# Skill — Context

This is the v2 Clay Functions framework skill.

**To use the skill:** invoke `/clay-functions-v2` in any conversation.

**Working in this folder** means improving the framework itself — SOPs, templates, references, the pre-publish checklist. If you're building an actual Function, go to `../functions/`.

## Structure

| Path | What it is |
|---|---|
| `SKILL.md` | Skill router — entry point, pointer table, opinionated positions |
| `sop/` | Step-by-step procedures (00 through 04) |
| `references/` | Mental model, failure modes, ADR guide |
| `assets/templates/` | Fillable templates: canvas, spec, usage-doc, ADR |
| `decisions/` | ADR log for framework-level design calls |
